# Sounds

## Placeholder ambience (built in)

The soundboard's four starter loops are generated by `src/placeholder-sounds.js` when the server
starts a request for them. They are 4-second mono 11 kHz WAVs, made from seeded noise and chirps,
so the same bytes come out every time and nothing binary is stored in git.

| id | name |
|---|---|
| `loop-rain` | Rain (placeholder) |
| `loop-tavern` | Tavern murmur (placeholder) |
| `loop-dungeon` | Dungeon drone (placeholder) |
| `loop-forest` | Forest wind (placeholder) |

**Licence:** made for this project by the project's own code and dedicated to the public domain
(CC0 1.0). Anyone may use, change and redistribute them without credit.

## One-shots (built in)

Thunder, sword hit, spell, roar and bell are synthesised in the browser (`public/audio.js`). No files.

## Your own sounds

Upload MP3, OGG, WAV, M4A, AAC, WebM audio, or FLAC from the soundboard. Uploads appear as layers
and one-shots, and survive restarts (files in `uploads/`). Up to six layers play at once.

## Replacing the placeholders later

If you add licensed library files, list each one here with its source, licence and author,
then add the entry to `loopItems()` in `src/placeholder-sounds.js` (or upload it as a DM sound).
Keep each file small: a 60-second loop at 128 kbps is about 1 MB.
